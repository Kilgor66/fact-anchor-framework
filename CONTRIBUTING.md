# Contributing

The goal is to develop a simple, testable, and continuously improvable AI response-control rule set.

## How to Contribute
The most valuable feedback is a **specific counterexample**: a case where the rule set produced a worse answer than the model produced without it.

Please submit an issue with:
1. The question asked.
2. The response generated with the rule set.
3. The response generated without the rule set.
4. Why you believe the rule-based response was inferior.

This helps us identify where rules are too strict, redundant, or incorrectly prioritized.
